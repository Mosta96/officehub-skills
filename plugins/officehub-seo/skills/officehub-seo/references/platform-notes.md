# Platform notes: where fixes are made (Shopify / WooCommerce)

officehub.sa runs on Shopify or WooCommerce (`references/officehub-profile.md` says which).
Before writing a fix, check which platform the site uses:
- **Shopify:** `cdn.shopify.com` assets, `Shopify.theme` in the source, `/products/` and
  `/collections/` URLs.
- **WooCommerce:** `wp-content` and `woocommerce` in the source, `/product/` and
  `/product-category/` URLs.

Then phrase every fix as *where to change it* on that platform, not "edit the HTML".
Settings, plugin and app names change: if a step does not match what the user sees, say so
and describe the goal instead.

## Shopify

| Area | What to know | Where the fix goes |
|---|---|---|
| URLs | `/products/`, `/collections/`, `/pages/`, `/blogs/` prefixes are fixed and cannot be removed. Don't recommend changing them | Product/collection "handle" in admin (adds a redirect automatically when changed if the box is ticked) |
| Duplicate product paths | Themes often link to `/collections/x/products/y`. The canonical points to `/products/y`, but internal links should too | Theme code: product card snippet, use `product.url` without `within: collection` |
| robots.txt | Generated by Shopify. Editable through a `robots.txt.liquid` template | Online Store → Themes → Edit code → add template `robots.txt` |
| Sitemap | Auto at `/sitemap.xml` (index with products, collections, pages, blogs). Cannot be edited directly | Remove an item by setting the `seo.hidden` metafield to `1` (this also noindexes it); unpublished items drop out on their own |
| Titles and meta descriptions | Per product, collection and page | "Search engine listing" section on each item |
| Structured data | Comes from the theme (often a basic Product block) and from apps. Check for duplicate Product blocks from theme + app | Theme code or the SEO/schema app settings |
| Languages (ar/en) | Shopify Markets + Translate & Adapt (or a translation app) with subfolders like `/en/`. Shopify adds hreflang for published languages | Settings → Languages / Markets. Check that every translated page is actually published |
| RTL | Depends on the theme supporting Arabic RTL | Theme settings; test the mobile menu and cart in RTL |
| Image alt text | Per media item | Product → media → "Add alt text". Set it per language through the translation tool |
| Speed | Apps inject scripts on every page. Uninstalled apps can leave code behind | Remove unused apps; check `theme.liquid` for leftover snippets |
| Redirects | URL redirects table | Online Store → Navigation → URL Redirects (or bulk import CSV) |
| Faceted filters | Filter URLs (`?filter.p.m...`) can be crawled at scale | Theme: `noindex` on filtered collection views, or disallow filter params in `robots.txt.liquid` |

## WooCommerce (WordPress)

| Area | What to know | Where the fix goes |
|---|---|---|
| URLs | `/product/` and `/product-category/` bases by default | Settings → Permalinks (changing bases on a live site needs 301 redirects) |
| SEO plugin | Titles, meta, canonicals, sitemaps and most schema come from one SEO plugin (Yoast, Rank Math, AIOSEO). Never run two at once | Plugin settings per product/category, plus global templates |
| robots.txt | Virtual file from WordPress or the SEO plugin | SEO plugin's file editor, or a real `robots.txt` in the web root |
| Sitemap | Usually the SEO plugin's sitemap (`/sitemap_index.xml`). Disable WordPress core `/wp-sitemap.xml` when a plugin provides one | SEO plugin → Sitemaps |
| Structured data | WooCommerce outputs basic Product JSON-LD; the SEO plugin may add more. Check for duplicate or conflicting Product blocks | SEO plugin schema settings, or a code snippet filter |
| Languages (ar/en) | WPML, Polylang or TranslatePress handle language URLs and hreflang. Check that every product has both languages linked | Translation plugin → language settings and per-product translation links |
| RTL | WordPress switches to RTL when the site language is Arabic, if the theme ships `rtl.css` | Theme choice; test with the Arabic language active |
| Faceted filters | `?filter_*`, `?orderby=`, `?min_price=` and layered-nav URLs can create crawl traps | `noindex` filtered views in the SEO plugin, canonical to the clean category URL |
| Out-of-stock | Keep the page live, mark availability, link alternatives. Only 301 when permanently discontinued | WooCommerce → Settings → Products → Inventory |
| Speed | Page builders, many plugins and unoptimized hosting are the usual causes. Caching + image optimization plugins | Host-level caching, WebP conversion plugin, remove unused plugins |
| Redirects | Through the SEO plugin's redirect manager or a redirection plugin | Plugin redirect manager |

## Both

- Apply Arabic and English changes to both language versions. Partial translations break
  hreflang parity (see `workflows/seo-hreflang/references/content-parity.md`).
- When a fix needs a developer (theme code), say so and give the snippet.
- Never recommend migrating platforms as an SEO fix.
